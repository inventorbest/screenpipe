# SearchWithGit Pipe

搜索、审查、总结你的数字生活上下文，包括屏幕录制和 Git 提交历史。

## 功能特性

### 屏幕历史搜索
- 音频转录搜索
- OCR 文本搜索
- UI 元素搜索
- 关键词过滤
- 窗口/应用过滤
- 说话人识别与过滤

### Git 提交历史搜索
- 递归扫描指定路径下的所有 Git 仓库
- 按提交作者筛选
- 按时间范围筛选
- 多仓库并行搜索
- 将 Git 提交信息作为上下文参与 AI 问答

## 使用方法

1. 在主界面搜索屏幕历史
2. 点击 "add git context" 按钮展开 Git 搜索面板
3. 输入 Git 仓库根路径（例如：D:\Projects 或 /home/user/projects）
4. 可选：设置作者、时间范围等筛选条件
5. 点击 "搜索 Git 提交" 获取提交记录
6. 勾选需要的提交记录
7. 在问答框中提问，AI 将结合屏幕历史和 Git 提交记录回答

## 示例场景

- "我上周在哪个项目上工作了？做了什么改动？"
- "找出所有关于登录功能的代码提交和相关的屏幕活动"
- "John 最近提交了什么代码？我们在会议中讨论过这些吗？"

## 技术说明

- 使用 Next.js API Routes 在服务端执行 git 命令
- 支持递归扫描多层目录结构
- 自动跳过 node_modules、.next 等常见构建目录
- 提交记录按时间倒序排列
